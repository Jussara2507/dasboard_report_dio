# 📊 Executive Sales Report | Dashboard Interativo

Painel executivo de vendas e análise financeira desenvolvido como projeto prático para o portfólio da **DIO (Digital Innovation One)**. O objetivo deste projeto é apresentar indicadores de desempenho comercial de forma dinâmica, utilizando tecnologias web modernas.

🔗 **Acesse o Dashboard Online:** [Ver no GitHub Pages](https://jussara2507.github.io/dashboard_reports_dio/)

---

## 🚀 Sobre o Projeto
O dashboard foi estruturado em um layout limpo (*dark mode* profissional) dividido em múltiplas abas temáticas, permitindo uma navegação fluida entre diferentes perspectivas de negócios:

* **Visão Executiva:** Indicadores principais (KPIs) de Vendas Brutas, Lucro Líquido, Unidades Vendidas e Margem Média, acompanhados de gráficos de desempenho por produto e distribuição por segmento.
* **Produtos:** Análise detalhada da evolução mensal das vendas e participação por categoria.
* **Geografia:** Panorama do faturamento distribuído por países e regiões estratégicas.
* **Metas e Indicadores:** Acompanhamento do atingimento de metas trimestrais e diretrizes operacionais.

---

## 🛠️ Tecnologias Utilizadas
O projeto foi construído do zero, priorizando performance e leveza sem necessidade de servidores complexos:
* **HTML5 & CSS3:** Estrutura semântica e estilização customizada com variáveis globais e layout responsivo (*Grid/Flexbox*).
* **JavaScript (ES6):** Lógica de controle para a alternância dinâmica entre as páginas do painel.
* **Chart.js:** Biblioteca em JavaScript para a renderização dos gráficos interativos (barras, linhas, rosca e pizza).
* **GitHub Pages:** Hospedagem estática contínua direto do repositório.
